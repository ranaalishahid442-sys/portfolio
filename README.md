## 🎨 Design Philosophy: Warm Craft Retro

This portfolio is built with the **Warm Craft Retro** design system:
- **Palette:** Oatmeal (`#FBF9F4`), Soft Terracotta (`#C46D5E`), Sage Green (`#5E8064`), and Warm Ochre (`#D4A373`).
- **Typography:** Space Grotesk, Plus Jakarta Sans, and JetBrains Mono.
- **Responsiveness:** Carefully tuned layouts for devices from 320px foldables to 4K desktop screens.
- **Interactions:** Hardware-accelerated 3D card tilt, dynamic role rotator, ambient glow particles, reading progress indicator, and smooth modal popovers.
